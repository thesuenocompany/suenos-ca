# Scrapbook visual rebuild

This release rebuilds the Sunfest photo-contest layout to match the approved scrapbook reference more closely.

Key changes:
- stronger editorial hero hierarchy
- exact logos placed in a readable lockup
- dark Sunfest backing badge without altering the logo
- layered paper, spiral binding, ticket stubs, masking tape and edge Polaroid
- overlapping prize ticket and stitched CTA
- form integrated into a taped paper sheet
- irregular Polaroid gallery with category ribbons, pins, tape and location label
- richer teal album footer
- responsive mobile composition with reduced decorative overlap

No contest data, entries, moderation records or winner records are changed.
