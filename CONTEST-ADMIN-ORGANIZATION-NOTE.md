# Contest Admin Organization Update

## What changed

- The main **Contests** view now excludes archived contests.
- A new top-level **Archived Contests** Admin tab contains inactive campaigns.
- Archived contests can be restored to **Draft** without recreating them.
- Retailer pages are grouped beneath their retail master campaign.
- Every contest has a clearly bounded card with its own action area.
- Contest type, operational status, entry count, URL and update time are separated into labelled fields.
- The primary actions are now consistent: Manage, Entries, Add Retailer Page where applicable, Duplicate and Archive.
- Archived cards use View / Edit, Entries and Restore to Draft.

Deploy the complete website package so the updated Admin page, cache-busted Admin JavaScript, Admin CSS and Netlify contest function are all replaced together.
