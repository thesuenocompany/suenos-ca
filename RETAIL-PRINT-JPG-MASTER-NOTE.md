# Retail Contest Master Poster + QR PDF Export

The retail contest print workflow now uses one master JPG poster rather than a PDF template.

## Master retail campaign

- Upload a JPG poster, or select the included 8 x 12 Sueños cooler poster.
- Set the physical PDF width and height in inches.
- Draw the QR placement box directly on the poster preview.
- Save the master poster and placement.
- The Admin shows the source pixel dimensions and effective print DPI.

## Retailer sub-contests

- Poster upload, print size and QR placement are inherited from the master campaign.
- These controls are read-only on retailer pages.
- Each retailer page has a Download Retailer Print PDF button.
- The generated PDF uses the retailer page's unique tracked contest URL.
- The JPG fills the full PDF page and the QR code is rendered as vector artwork.
